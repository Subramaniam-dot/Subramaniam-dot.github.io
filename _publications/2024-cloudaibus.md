CloudAIBus is an AI-based testbed for cloud computing environments focusing on effective resource allocation using deep learning models. The framework leverages the DeepAR model for robust CPU usage forecasting, reducing unused CPUs from 98.65% to 32.35% compared to baseline approaches.
