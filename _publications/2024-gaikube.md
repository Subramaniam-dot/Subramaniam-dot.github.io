GAIKube is a threefold framework offering Generative AI-enabled proactive container orchestration for heterogeneous edge computing. The orchestrator produces container scheduling, migration, dynamic vertical scaling, and hosted application model-switching to balance SLA violations, cost, and accuracy objectives. GKE-based experiments show 3.43% SLA violations and 3.80% accuracy loss with zero server faults.
