GAIKube is a threefold framework that offers generative-AI-enabled proactive container orchestration for heterogeneous edge computing. The orchestrator handles container scheduling, migration, dynamic vertical scaling and model switching for hosted applications, balancing SLA violations, cost and accuracy. Experiments on Google Kubernetes Engine show 3.43% SLA violations and 3.80% accuracy loss with zero server faults.
