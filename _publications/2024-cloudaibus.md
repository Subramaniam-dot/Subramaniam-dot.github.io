CloudAIBus is an AI-based testbed for cloud computing environments that focuses on effective resource allocation using deep learning. The framework uses the DeepAR model for robust CPU-usage forecasting, reducing unused CPUs from 98.65% to 32.35% compared with baseline approaches.
